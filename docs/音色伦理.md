# 音色使用伦理

声音是身份数据。克隆一个人的声音，比公开他的照片严重得多——照片只能被看，
声音可以被拿去冒充他本人说话。本项目不提供任何绕过这一点的便利。

## 必须遵守

1. **只克隆你自己的声音，或已取得明确、知情、可撤回同意的人的声音。**
   口头同意不够，留痕。
2. **不做冒充。** 不用克隆音色伪装他人身份去通话、发语音、过声纹验证。
3. **不克隆公众人物或任何你没有权限的人。**
4. **下载素材前确认你有权使用它。** 从视频、播客、歌曲里抽人声来训练，
   多数情况下你并没有这个权利。
5. **公开分发用克隆音色生成的音频时，标明它是合成的。**
6. **不用于骚扰、诈骗、伪造证词、色情内容、政治造谣。**

## 关于本项目训练出的音色

`config.json` 里每个 profile 都是一个具体的人。它们连同参考音频、数据集、
训练产物一起被 `.gitignore` 排除，**不会进入版本库，也不会随发布流出**。
如果你在自己的仓库里改了 `.gitignore`，请先确认你没有把别人的声音提交上去。

删掉一个人的音色 = 删 `models/voices/<名字>/`、`data/<名字>/`、
`data/refs/<名字>*`，并从 `config.json` 的 `profiles` 里移除该条目。
对方要求撤回同意时，这就是你该做的全部事情，几分钟就能做完。

## 本项目自身不承担的内容

本项目的代码不含声纹绕过、不含实时变声器、不含"伪造成通话"的能力，
也不附带任何真人音色或数据集。它做的是：你把自己的干声喂进去，得到你自己的
声音模型。这个边界是刻意设计成这样的。
